🌀 Попрыгунчик (Jumper)
Динамичная браузерная аркада на JavaScript, вдохновленная классикой жанра Doodle Jump. Управляйте Колобком, прыгайте по платформам и заберитесь как можно выше!

✨ Особенности игры
Живая анимация: Реализован принцип Squash & Stretch — герой забавно сплющивается при приземлении и вытягивается в прыжке, создавая эффект «мягкости».

Интерактивный мир:

Обычные платформы: Твердая опора для прыжка.

Движущиеся платформы (MOVING): Синие платформы, которые перемещаются из стороны в сторону, проверяя ваш тайминг.

Тонущие платформы (SINKING): Уникальная механика — платформа проседает под весом героя «ступеньками» при каждом прыжке и плавно возвращается назад.

Физика отдачи: Каждая платформа визуально пружинит (bump effect) при контакте с игроком.

Сквозной мир: Реализована механика перехода через края экрана (улетел влево — появился справа).

Умная генерация: Алгоритм следит, чтобы платформы не наслаивались друг на друга и всегда находились в пределах досягаемости прыжка.

🕹 Управление
A / ← — Движение влево.

D / → — Движение вправо.

Enter — Перезапуск игры после проигрыша (экран Game Over).
